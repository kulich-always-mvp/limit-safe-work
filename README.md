# limit-safe-work

Скилл для ИИ-агентов (Claude Code, Codex и другие): долгая многошаговая работа, которую не ломают лимиты.

Если лимит (5-часовой или недельный) кончился посреди задачи, контекст сжался или началась новая сессия, ничего не теряется. Агент после каждого шага записывает прогресс в файл `HANDOFF.md` в папке проекта, а новая сессия по команде «продолжи» восстанавливает контекст из этого файла и продолжает с того же места. Заодно скилл учит агента экономить токены, чтобы лимит кончался позже.

## Как это работает

1. **Чекпоинты.** После каждого готового шага агент обновляет `HANDOFF.md`: цель, ваши требования дословно, принятые решения, что сделано, что следующее.
2. **Возобновление.** Напишите «продолжи». Агент прочитает файл, сверит его с реальным состоянием проекта и продолжит, не начиная заново.
3. **Экономия.** Агент ищет перед тем, как читать, читает только нужные куски, правит точечно и не пересказывает в чате то, что уже записано в файлы.

## Установка

Скопируйте папку `limit-safe-work/` в одно из мест:

- `~/.claude/skills/limit-safe-work` (на Windows `%USERPROFILE%\.claude\skills\limit-safe-work`), чтобы скилл работал во всех проектах;
- `.claude/skills/limit-safe-work` внутри проекта, чтобы он работал только там.

Скилл включается сам на задачах больше чем на несколько шагов, а также когда вы пишете «продолжи», «на чём остановились», «лимит кончился».

## Советы

- В `HANDOFF.md` не попадают пароли и ключи. Если проект под git, добавьте `HANDOFF.md` в `.gitignore`.
- Когда задача закончена, агент спросит, удалить файл или оставить его как историю решений.
