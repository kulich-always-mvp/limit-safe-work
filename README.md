# limit-safe-work

Скилл для ИИ-агентов (Claude Code, Codex и другие): долгая многошаговая работа, которую не ломают лимиты.

Если лимит (5-часовой или недельный) кончился посреди задачи, контекст сжался или началась новая сессия, ничего не теряется. Агент после каждого шага записывает прогресс в файл `HANDOFF.md` в папке проекта, а новая сессия по команде «продолжи» восстанавливает контекст из этого файла и продолжает с того же места. Тот же файл можно по команде превратить в документ для передачи работы другому агенту или в новый чат. Заодно скилл учит агента экономить токены, чтобы лимит кончался позже.

## Как это работает

1. **Чекпоинты.** После каждого готового шага агент обновляет `HANDOFF.md`: следующий шаг, что сейчас в работе (включая незакоммиченные правки), цель, ваши требования дословно, принятые решения, что сделано.
2. **Возобновление.** Напишите «продолжи». Агент прочитает файл, сверит его с реальным состоянием проекта и продолжит, не начиная заново.
3. **Передача.** Напишите «сделай handoff» или «перенеси в новый чат». Агент доведёт файл до такого состояния, чтобы по нему мог продолжить тот, кто не видел разговора: подстроит под задачу следующей сессии, заменит пересказ ссылками на коммиты и спецификации, укажет, какие скиллы вызвать, и вычистит секреты. Самое срочное записывается первым, поэтому даже прерванная передача полезна.
4. **Экономия.** Агент ищет перед тем, как читать, читает только нужные куски, правит точечно и не пересказывает в чате то, что уже записано в файлы.

## Когда файл не создаётся

- Короткие задачи (меньше ~5 шагов) обходятся планом в чате.
- В обычном чате без папки проекта чекпоинтов нет: большой результат пишется сразу по частям в артефакт или документ, а по команде «передай» агент выдаёт содержимое одним блоком, которое можно вставить в новый чат.

## Несколько задач в одной папке

Для второй задачи или параллельно работающего агента заводится отдельный файл `HANDOFF-<задача>.md`. Если незавершённых файлов несколько, по «продолжи» агент спросит, какую задачу продолжать.

## Установка

Скопируйте папку `limit-safe-work/` в одно из мест:

- `~/.claude/skills/limit-safe-work` (на Windows `%USERPROFILE%\.claude\skills\limit-safe-work`), чтобы скилл работал во всех проектах;
- `.claude/skills/limit-safe-work` внутри проекта, чтобы он работал только там.

Скилл включается сам на задачах примерно от 5 шагов, а также когда вы пишете «продолжи», «на чём остановились», «лимит кончился», «сделай handoff», «перенеси в новый чат».

## Советы

- В `HANDOFF.md` не попадают пароли и ключи. Если проект под git, добавьте `HANDOFF.md` в `.gitignore`.
- Когда задача закончена, агент спросит, удалить файл или оставить его как историю решений.
